# Character photos

Drop character images here, then commit & push (or tell Claude to `git pull`).

Recommended:
- One person per file
- PNG with a **transparent background** (cut-out) for animated characters
- Reasonable resolution (e.g. 600–1200px tall)
- Simple, descriptive filenames, e.g.:
  - villager-1.png, scribe.png, settler-1.png, elder.png ...

Normal rectangular photos (jpg) also work — they'll be shown in framed
portrait cards with motion instead of free-floating cut-outs.
